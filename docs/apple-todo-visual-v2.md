## 二、动手之前要知道的三件事

### 1. 试点那步补图，我们没按 §三.1 的 `[3,3,3,1]` 写

用的是 **`[3,2,3,3]`**（三分之二 对 一整条），caption「三分之二连一整条都不到，哪来的比一整条多」。

把 `[3,3,3,1]` 用真渲染器画出来之后，三个问题：

- 出来是**两条分离、异色**的横条，右侧强制各标 `3/3` 和 `1/3`，屏幕上从头到尾没有「4/3」；
- 「上下两条并排」正是这一课教**比大小**的固定句式——同一课 step 3 就是 `[4,3,12,9]` = 3/4 vs 9/12。用同一个句式表示相加，等于让孩子拿比大小的眼睛去读加法；
- 关键是：这套「一整条 + 余数」的惯例是 **G6 `mixed-numbers` 主题**教的（`MIXED.MODEL`、`IMPROPER.TO_MIXED`），而试点这步是 **G5**。孩子走到这里还没见过这个句式。

正解是把 4/3 当一个数画出来（见下面 P1）。你们上了那个能力之后，这步会升级成 `[3,2,3,4]`——三分之二 对 三分之四，那才是这句课文真正在说的话。

### 2. 你们那份 685 行 CSV 漏了三类问题

CSV 统计的是 `visual.type == "none"`，所以下面这些 **type 不是 none、却在屏幕上是错的或空的**，一条都没进清单：

| 症状 | 步数 | 屏幕上是什么 |
|---|---|---|
| 比 1 大的分数画不了，靠两张图凑 | 15 | 两张图各标 `4/4`、`3/4`，「7/4」从未出现 |
| 数轴打不出分数刻度，点标成小数 | 44 | 图注写「四分之三和十二分之九同一个点」，画面上是 **0.75** |
| `placeValue` 六位以上整步空图 | 31 | 讲「十万位、百万位」的课，一张图都没有 |

**其中 3 处就在试点主题里**：`zh EQUIV.JUDGE #2 / #3`，以及 `EQUIV.NUMBERLINE` 大半节课
（那节课的教学装置就是「把 0 到 1 剪成几格、数格子不数线」，可现在图上一根小刻度都没有，
#4 专门表演的「数线 vs 数格」误区根本演不出来）。**孩子试点会看到这几张。**

### 3. 越界处理，我们向你们对齐了

web 端原来是**静默钳位**（`fractionBar [3,4]` 的分子被钳成 3，画出满格的 3/3，而课文正在说
「三分之四比一整条还多」）。现在改成和你们一样：**违约 → 降级成无图**。
理由就是你们那句「宁可不配图，也不能配错图」——看图模式下图是正文，画错严格差于不画。
从此同一份数据在两端只有一种失败方式。

**(c) 试点话术先想好上面第 2 条。** `EQUIV.JUDGE #2/#3` 和 `EQUIV.NUMBERLINE` 整节课的数轴图，

别把孩子对这几张图的反应归到补图批次头上。

### P1 · 两个渲染能力（几何规格见 [visual-contract-v2.md](visual-contract-v2.md) §2，有公式、颜色、间距）

**A `improperFraction`** —— `fractionBar` / `pie` 认 `n > d`：画 `ceil(n/d)` 个整体连排、
**同色**、整组只标一次 `n/d`。两条并排时整体宽度按最多的那条取齐（不然「同一个整体」在图上就是假话）。
同色 + 单标签是刻意的：把「加」和「比」在视觉上分开。

**B `numberLineSubdivision`** —— `nums[4]` = 每一整格再平分几小份：打半高小刻度、
**只标整数刻度**、标记点标成分数（整数在左、分数竖着摞在右，纯 SVG 不用 LaTeX）、
**给了分母就不画跳跃箭头**（那个场景是比大小）。点必须正好落在刻度上，落不到就不画。
**纯增量**：不给第 5 个数的老内容渲染结果一个像素不变。

自测这几组，画出来应该分别是：

```
fractionBar [3,4]            → 两个整条连排，涂 4/6 格，标 4/3
fractionBar [3,2,3,4]        → 上条 2/3、下条 4/3，两条的「一个整体」等宽
pie         [4,7]            → 两个整圆，第二个涂 3/4，整组正中标 7/4
numberLine  [0,1,0.75,0.75,4]→ 四等分小刻度，只标 0 和 1，点上标竖式 3/4
numberLine  [0,1,0.6667,0.75,12] → 十二等分，两个点标 8/12 和 9/12，无箭头
numberLine  [0,3,2.75,2.75,4]→ 带分数 2¾
```

### P2 · `placeValue` 排到十亿位

我们原来卡在 `n >= 100000 return ""`，位值标签表只有五个（个位…万位），

已扩到 `个位…十亿位` / `Ones…Billions`，上限 `1e10`。**你们那边大概率有同样的坑，查一下。**
